Cache Locality Visualizer

Spatial Locality

When the CPU accesses a memory location, it is likely to access nearby memory addresses soon after. CPUs take advantage of this by loading a whole cache line instead of only the requested value. Sequential array access is a common example.

Temporal Locality

When the CPU accesses a memory location, it is likely to access the same location again in the near future. Keeping recently used data in cache makes these repeated accesses much faster than fetching it again from main memory.
